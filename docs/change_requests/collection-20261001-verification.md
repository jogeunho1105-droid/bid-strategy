## 평가기준과 S1~S5

같은 개찰일의 모든 예측을 먼저 수행하고 그 날의 결과를 학습에 추가했다. 미래 결과·실제 경쟁업체수를 목표 특징으로 사용하지 않았다. burn-in 150건, 기존 타 권역 한전 지역제한 제외, 미분류·단가감리·소표본·동일공고 결과 오염에 관한 현행 앱의 산정보류를 동일하게 적용했다. 개발 종료 2025-08-31, 고정 보류기간 2025-09-01~2026-09-01, 최종검증 2026-06-01~2026-09-23을 양쪽에 고정했다. 정정차수와 정책 적용일은 소급하지 않았다.

`예가 < 추천 < 1순위`의 엄격 부등식과 v2.15.7 기준 분모를 유지했다. 1순위 누락/abs>=10은 판정 분모에서 제외하고 숫자 비양수 구간은 실패로 남겼다. 최소오차는 다중추천 커버리지이고 중심/단일 오차와 분리했다. 전략·정책·가중치를 데이터 결과에 맞춰 재선택하지 않았다. 자동전략은 현행 적용일을 지키므로 고정 과거 보류구간에서 S1과 같다.

백테스트는 실제 `recommend_bids`의 예측 루프를 추출해 일자별 공유 상태에서 실행했다. 수식은 수정하지 않고 같은 날 동일 이력 창·가중치·구간 배열만 재사용했다. 순서가 보장된 창의 이진검색 및 중간 배열 캐시는 실제 앱 결과와 정확 일치하는 회귀검사를 통과했다. 평가와 앱 추천에 사용하는 engine/rules/legacy/strategies/policy 파일은 변경 전 Git 내용과 동일하다.

### 표본 구성 변화와 운영전략 해석

전체 운영전략 판정가능은 36,564→70,564건, 통과율은 15.06%→15.84%다. 그러나 기존은 2023년 이후, 신규는 2019년 이후까지 포함하므로 전체 통과율 상승을 같은 표본의 성능 개선으로 해석하지 않는다. 고정 보류구간은 S1/자동이 소폭 하락했고, 고정 최종검증에서 S1은 15.28%→14.86%다.
