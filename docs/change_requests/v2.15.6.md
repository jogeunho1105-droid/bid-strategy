# v2.15.6 변경요청서

작성일: 2026-09-02
기준 버전: v2.15.5
변경 주제: 엄격 가상 낙찰 검증정보 표시와 실제 투찰성과 수집 구조 추가

## 1. 변경 목적

2026-09-01까지의 낙찰이력으로 수행한 일자별 rolling backtest와 공고별 가상 낙찰 검증 결과를 운영 프로그램에 투명하게 표시한다. 동시에 이후 추천값의 관측 실제 성과를 검증할 수 있도록 추천 당시 값과 개찰 후 실제값을 연결하는 기록지를 제공한다.

## 2. 확정 반영사항

1. 앱 버전을 v2.15.6으로 표시한다.
2. 사이드바에 최근 엄격 백테스트 기준일, 최근 1년 가상 낙찰률과 중심·단일값 가상 낙찰률을 표시한다.
3. 가상 낙찰률이 실제 당사 참여기록이 아닌 반사실적 검증값임을 명시한다.
4. 추천표 Excel에 `사후낙찰검증`과 `검증기준` 시트를 추가한다.
5. 사후기록에는 공고정보, 업체별 추천값, 당사업체, 적용 추천순번, 실제 투찰사정률, 예가/기초, 1순위 사정률, 낙찰하한율, 무효·실격 여부, 최종결과와 메모를 포함한다.
6. 추천기준과 실제투찰 기준의 판정은 `예가/기초 < 평가값 < 1순위 사정률`의 엄격 부등식으로 계산한다.
7. 업로드한 낙찰이력의 최초일과 최종일을 데이터 품질 정보에 추가한다.

## 3. 변경하지 않는 사항

- 업체1 방향성 헷지, 업체2 중심모델, 업체3 라인 헷지 추천식과 가중치
- 한전 감리 지역제한/전국입찰 이력 분리
- 경북·대구 지역제한 1개사, 부산울산 금액별 2·3개사, 한전 전국감리 3개사 기준
- 전기공사 별도 분류와 1개사 단일추천
- 화면과 Excel에 실제 참여 가능한 업체만 표시하는 원칙

개발구간에서 선택된 다중참여 +0.12%p, 전기공사 +0.19%p, 한전 지역 1개사 +0.12%p 상향보정은 최근 1년 고정 보류구간의 일자 블록 95% 신뢰구간이 0을 포함해 적용하지 않는다.
