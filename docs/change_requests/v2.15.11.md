## 1. 용어와 적용전략
본 기능은 **관측 순위 기반 시험운영**이다. `예가/기초 < 추천사정률 < 1순위사정율` 가격구간 통과율은 실제 당사의 낙찰확률이 아니다. 신규 전략의 미래 우위나 참가자격을 보증하지 않는다.

기본 자동선택은 2026-09-27 재현연구의 관측 순위에 근거한다.
- 전기공사: S4 가격구간 중심대체(573/6538). 1개사에서 S5와 동일.
- 건설사업관리: S3 시간가중 분위수(489/943). 시장 참고자료의 결과.
- 기존사업 묶음: S3 시간가중 분위수(228/4304). 각 발주기관별 1위라는 뜻이 아니고 신규전략 통계적 우위도 미확정.
- S1 현행 계산과 S2~S5를 직접 선택할 수 있다. S5는 최근기간 비교후보로 유지하며 유리한 기간의 성과만 조합해 자동선택하지 않는다.

## 2. 정정공고
현재 입찰서류함의 같은 공고번호 root, 발주기관 및 명시 공구 안에서 마지막 숫자 차수의 최댓값만 유지한다. -10이 -2보다 크다. 낮은 차수의 원본·제외사유·대체 공고번호를 보존한다.
동일 최고차수 완전동일 입력은 1행만 유지; 내용 충돌은 보류한다. 최고차수 취소 시 하위차수 부활 금지.
기초금액·하한율·마감은 최고차수 행을 사용한다. 과거 학습이력 전체를 미래 정정차수로 소급 삭제하지 않는다. 현재 대상공고의 과거차수 결과 누출은 별도 차단한다.

## 3. 고정 후보 계산
S1: 기존 공유엔진 및 날짜별 기존 정책, 1/2/3개사 분기 유지.
S2: 최근365일 기관50/분야200건, 기관 m/(m+20) 강건중심 혼합.
S3: 최근730일 모델군2000/기관300건, 반감기180일, 기관 m/(m+60) 혼합. 1개사 Q50, 2개사 Q30/Q70, 3개사 Q20/Q50/Q80.
S4: 다른 슬롯 유지, 0.02%p 격자와 ±0.10%p 평활화의 과거 가격구간 점수로 중심값 대체.
S5: 같은 점수로 이미 포괄한 구간을 고려하여 허용업체수만큼 순차선택. 전역최적 보장 없음.
현재 공고의 결과를 보며 가중치/구간을 조정하지 않는다.

## 4. 소표본 보완
- 동일 모델군·입찰범위에서 730일 → 필요시1460일로 확장. 출처·기간·이유 표시.

- 대체/기간확장값에는 기존 원전략의 연구통과율을 적용하지 않는다. 이 표본 하한은 운영상 안전조건이지 통계적 유의성의 보장이 아니다.
