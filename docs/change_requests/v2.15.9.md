# v2.15.9 변경요청서

## 1. 변경 목적

나라장터 입찰서류함 XLS/XLSX를 업로드하여 투찰전략을 분석한 뒤, 화면의 핵심 추천결과를 간단한 Excel 파일로 내려받을 수 있도록 한다.

기존 상세 Excel은 유지하고, 사용자가 제시한 형식과 같은 별도의 **투찰전략 요약 다운로드**를 추가한다.

## 2. 적용 대상

- 투찰전략 분석 화면에서 업로드하는 나라장터 입찰서류함 XLS/XLSX
- 업로드 파일에 `낙찰하한율` 열이 있는 공고
- 1개사·2개사·3개사 참여 공고 모두 적용
- 분석 모델군과 발주기관 구분에 관계없이 적용

첨부된 `입찰서류함_20260922 (1).xlsx`의 `서류함` 시트에는 다음 열이 확인된다.

- 공고명
- 공고번호
- 기초금액
- 투찰마감
- 지역
- 발주기관
- 업종
- 낙찰하한율

## 3. 확정 출력 형식

### 3.1 요약 다운로드 열 순서

```text
공고명 | 낙찰하한율 | 업체1추천 | 업체2추천 | 업체3추천
```

### 3.2 값 표시 기준

- `공고명`: 입찰서류함 원문 전체 표시
- `낙찰하한율`: 입찰서류함의 원본 값을 그대로 사용
- `업체1추천`~`업체3추천`: 최종 추천 사정률 표시
- 추천 사정률 표시 형식: `+0.0161%`, `-0.5479%`
- 참여하지 않는 업체: `참여대상 없음`
- 분석 데이터 부족: `없음`
- 낙찰하한율 누락 또는 숫자 변환 실패: `미확인`

`낙찰하한율`은 앱에서 재계산하거나 추정하지 않는다. 반드시 업로드한 입찰서류함의 원본 값을 사용한다.

## 4. 입력 파싱 변경

`parse_xls()`의 XLS/XLSX 양쪽 파서에서 `낙찰하한율`을 읽어 각 공고 객체에 저장한다.

권장 내부 키:

```python
bid["lower_limit_rate"]
```

처리 기준:

1. `89.745`, `89.745%`, 숫자 셀을 모두 허용한다.
2. 내부 값은 퍼센트 숫자 `89.745`로 통일한다.
3. 빈 셀·문자 오류는 `None`으로 저장한다.
4. 파싱 오류가 있어도 해당 공고의 추천분석은 중단하지 않는다.

## 5. 다운로드 기능

기존 `업체 추천표 다운로드`는 유지한다.

그 아래에 별도 버튼을 추가한다.

```text
📥 투찰전략 요약 다운로드
```

권장 파일명:

```text
투찰전략_요약_YYYYMMDD.xlsx
```

권장 시트명:

```text
투찰전략
```

### 5.1 Excel 서식

- 제목행: `투찰전략 분석 — v2.15.9 / YYYY.MM.DD`
- 헤더 고정
- 자동필터 적용
- 공고명 열 너비 60 전후, 줄바꿈 적용
- 낙찰하한율 열 너비 15 전후, 중앙 정렬
- 업체 추천 열 너비 각 15 전후, 중앙 정렬
- 추천값은 양수·음수 4자리 형식
- `참여대상 없음`과 `없음`은 텍스트로 유지
- 전체 셀에 얇은 테두리 적용

## 6. 화면 표시 기준

현재 v2.15.8 화면 요약표의 열 순서와 표시 기준은 변경하지 않는다.

```text
중심모델군 | 공고명 | 업체1추천 | 업체2추천 | 업체3추천 | 비고
```

이번 변경은 **다운로드 Excel 추가**가 주목적이다. 화면에 `낙찰하한율`을 추가하려면 별도 승인사항으로 처리한다.

- 한전 지역제한·전국입찰 이력 분리
- 전기공사 단일추천
- 최근 90일 가중치와 보정
- 추천기준금액 계산
- 기존 상세 Excel의 모든 시트와 열
- 백테스트 엔진과 정책 파일

## 9. 회귀검증 기준

### 9.1 파싱 검사

- XLS 숫자 `89.745` → `89.745`
- XLSX 숫자 `89.745` → `89.745`
- 문자열 `89.745%` → `89.745`
- 빈 값 → `None`
- 비정상 문자열 → `None`

### 9.2 출력 검사

- 열 순서가 정확히 `공고명, 낙찰하한율, 업체1추천, 업체2추천, 업체3추천`
- 1개사 참여 시 업체2·3은 `참여대상 없음`
- 2개사 참여 시 업체3은 `참여대상 없음`
- 3개사 참여 시 추천값 3개 표시
- 추천값이 기존 화면·상세 Excel 결과와 0.0000%p 차이
- 낙찰하한율 누락 시 `미확인`
- 기존 상세 Excel 생성 결과가 v2.15.8과 동일
