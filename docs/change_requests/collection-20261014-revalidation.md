## 전체 rolling S1~S5 및 운영전략 재실행

기존 유효 46,665건·신규 유효 90,831건 전체를 일자 순서로 다시 평가했다. 각 일자의 예측을 끝낸 뒤 그 일자의 결과를 추가하며 burn-in 150건, 기존 산정보류, 정책 적용일과 `예가 < 추천 < 1순위` 기준을 동일하게 유지했다. 결측 1순위는 평가 분모에서 제외한다. 평가일·전략·가중치를 다시 선택하지 않았다. 기존은 482초, 신규는 1,649초 걸렸다.
