# v2.15.4 변경요청서

작성일: 2026-08-18
기준 버전: v2.15.3
변경 주제: 이력 정렬 재현성 고정, 최근 90일 오버레이 보수화, 데이터 품질·백테스트 추적성 강화

## 1. 변경 목적

이번 변경의 목적은 다음 세 가지다.

1. 동일한 낙찰이력을 사용해도 동일 개찰일 내 행 순서에 따라 추천값이 달라지는 문제를 제거한다.
2. 최근 90일 흐름이 중심모델을 과도하게 이동시키지 않도록 오버레이 가중치를 보수적으로 낮춘다.
3. 낙찰이력의 완전 동일 중복, 목표값 누락, 지역 누락을 명시적으로 처리하고 화면·엑셀에서 산정 근거와 데이터 품질을 확인할 수 있게 한다.

검증 결과, 현행 날짜 단독 정렬은 표본 15건 중 12건에서 추천값이 달라졌고 최대 차이는 1.2386%p였다. 동일일 정렬 기준을 고정한 후 원본 v2.15.3 함수와 백테스트 엔진은 15건 모두 0.0001%p 이내로 일치했다.

최근 1년 11,982건에서 최종 제안안은 현행 대비 MAE가 0.384224%p에서 0.384062%p로 낮아졌고, ±0.30%p 적중률은 52.4286%에서 52.5288%로 높아졌다. 개선 폭은 작으므로 전기공사와 한전 지역제한 1개사 전용 가중치는 변경하지 않는다.

## 3. 확정된 계산 기준

### 3.1 데이터 정렬과 전처리

분석용 이력은 다음 순서로 안정 정렬한다.

~~~python
history.sort_values(
    ["개찰일", "공고번호", "번호"],
    kind="mergesort",
)
~~~

- 날짜 우선순위: 개찰일 → 입찰일 → 공고일 → 마감 → 투찰마감
- 같은 날짜에서는 공고번호, 번호를 오름차순 보조키로 사용한다.
- 예가/기초(0%)가 비어 있거나 절댓값이 10% 이상인 행은 학습·백테스트에서 제외한다.
- 모든 컬럼이 같은 완전 동일 중복행만 1건으로 축약한다.
- 공고번호가 같더라도 개찰일·결과가 다른 재공고·재개찰은 유지한다.

### 3.2 업체2 중심모델

v2.15.3의 용역분류별 중심모델을 유지한다.

| 용역분류 | 중심모델 |
|---|---|
| PD | 전체 최근 20건 |
| VLF | 가중혼합 |
| 콘크리트 | 평균혼합 |
| 건설사업관리 | 평균혼합 |
| 설계 | 평균혼합 |
| 진단기타 | 발주처+용역성격 유사패턴 최근 5건 |
| 광학 | 가중혼합 |
| 기타 | 평균혼합 |
| 감리 | 평균혼합 |
| 초음파 | 발주처 최근 20건 |
| 전기공사 | 가중혼합 |

가중혼합의 기본식도 유지한다.

~~~text
가중혼합 =
  0.35 × 발주처 최근20건
+ 0.25 × 발주처·동일분야 최근20건
+ 0.20 × 동일분야·금액구간 최근20건
+ 0.10 × 동일분야 최근20건
+ 0.10 × 전체 최근20건
~~~

사용 가능한 항목만 포함하고 실제 적용 가중치 합으로 다시 나눈다.

기관·분야별 내부 라우터도 유지한다.

| 기관구분 | 분야 | 내부 모델 |
|---|---|---|
| 기타 | 진단기타·기타·설계 | 베이지안 축소평균 |
| 조달청 | 감리 | 베이지안 축소평균 |
| 조달청 | 건설사업관리 | 축소 AR(1) |

### 3.3 최근 90일 오버레이 변경

적용 표본 우선순위는 기존과 같다.

1. 동일 발주기관·동일 분야
2. 동일 발주기관
3. 동일 분야
4. 전체 이력

선택 표본이 8건 이상이고 최근 90일 표본이 5건 이상일 때만 적용한다.

~~~text
drift = 최근90일평균 - 선택표본전체평균

v2.15.4 중심값 =
clip(
  (1 - w90) × 기본중심값
  + w90 × 최근90일평균
  + 0.04 × drift,
  선택표본 5% 분위수,
  선택표본 95% 분위수
)
~~~

| 최근 90일 표준편차 | v2.15.3 가중치 | v2.15.4 가중치 |
|---|---:|---:|
| 0.55%p 미만 | 0.18 | 0.10 |
| 0.55%p 이상 | 0.12 | 0.05 |
| drift 추가가중 | 0.08 | 0.04 |

전기공사 단일참여와 한전 지역제한 1개사는 이 변경에서 제외하고 아래 기존 전용식을 유지한다.

### 3.4 한전 지역제한 1개사 보정

경북본부·대구본부 지역제한 감리 1개사 보정은 v2.15.3 그대로 유지한다.

~~~text
최근중심 = 0.45 × 최근3건평균
         + 0.35 × 최근5건평균
         + 0.20 × 최근10건평균

최종값 = clip(
  (1 - w_local) × 업체2중심값 + w_local × 최근중심,
  지역제한 표본 5% 분위수,
  지역제한 표본 95% 분위수
)
~~~

| 최근 10건 표준편차 | w_local |
|---|---:|
| 0.55%p 미만 | 0.35 |
| 0.55%p 이상 | 0.25 |

지역제한 이력이 8건 미만이면 보정을 적용하지 않는다.

### 3.5 전기공사 단일참여

전기공사 전용 가중치는 변경하지 않는다. 최근 1년 표본 3,856건에서 대안 가중치의 MAE 차이 95% 신뢰구간이 0을 포함하여 개선을 확정할 수 없었다.

| 요소 | 현행 가중치 | 적용 조건 |
|---|---:|---|
| 동일 발주기관 | 0.35 | 10건 이상 |
| 동일 발주기관 | 0.25 | 5~9건 |
| 동일 지역 | 0.20 | 8건 이상 |
| 동일 금액구간 | 0.20 | 10건 이상 |
| 동일 업체수구간 | 0.10 | 10건 이상 |
| 최근 1년 | 0.20 | 20건 이상 |
| 최근 90일 | 0.15 | 10건 이상, 표준편차 0.55%p 미만 |
| 최근 90일 | 0.10 | 10건 이상, 표준편차 0.55%p 이상 |

사용 가능한 요소만 포함해 가중평균하고, 최근 전기공사 300건의 5~95% 분위수로 제한한다. 전기공사 유효 표본이 20건 미만이면 업체2 중심값을 사용한다.

### 3.6 업체1·업체3과 추천기준금액

- 업체1: 발주처 전체와 동일 분야의 부호 전이패턴 및 직전 2건 차이를 사용하는 방향성 헷지
- 업체2: 위 중심모델
- 업체3: 발주처 이력을 0.02%p 라인으로 묶고 직전 패턴 이후 최다빈도 라인을 선택하는 라인 헷지

추천기준금액은 기존과 같이 계산한다.

~~~text
추천기준금액 = int(기초금액 × (100 + 추천사정률) ÷ 100)
~~~

이 값은 낙찰하한율을 반영한 최종 투찰금액이 아니므로 화면과 엑셀의 명칭을 입찰가가 아니라 추천기준금액으로 통일한다.

## 4. 변경하지 않을 기존 로직

1. 운영 파일명 입찰 앱.py와 Streamlit Main file path를 유지한다.
2. 한전 감리는 지역제한과 전국입찰 이력을 분리한다.
3. 부산울산본부 지역제한 감리는 2개사 추천을 유지한다.
4. 경북본부·대구본부 지역제한 감리는 1개사 추천을 유지한다.
5. 한전 전국 감리는 전국입찰 실적 보유 3개사 추천을 유지한다.
6. 전기공사는 감리·설계·진단과 분리하며 1개사 단일추천을 유지한다.
7. 업체1은 방향성 헷지, 업체2는 중심모델, 업체3은 라인 헷지 역할을 유지한다.
8. 화면과 엑셀에는 실제 참여 가능한 업체의 추천값만 표시한다.
9. 사용자 승인 전 GitHub main 반영과 Streamlit 운영 배포를 하지 않는다.

## 5. 백테스트 방법

- 입력 파일: 낙찰데이터.xlsx
- 원천 행수: 55,781행
- 완전 동일 중복 제거: 31행
- 중복 제거 후 유효 낙찰이력: 45,731행
- 백테스트 표본: 45,579건
- 데이터 기간: 2023-01-02 ~ 2026-08-12
- 백테스트 기간: 2023-01-13 ~ 2026-08-12
- 초기 학습량: 해당 일자 이전 전체 유효이력 150건
- 방식: 개찰일 단위 rolling backtest
- 정보 제한: 각 일자의 추천값은 해당 일자보다 앞선 결과만 사용
- 동일일 처리: 같은 개찰일 결과는 전부 예측한 후 이력에 일괄 추가
- 평가대상: 예가/기초(0%)
- 다중 업체 평가: 실제 참여 가능한 추천값 중 실제값과 가장 가까운 값의 절대오차
- 단일 업체 평가: 단일 추천값의 절대오차
- 하한미달위험: 모든 적용 추천값이 실제값보다 0.50%p 초과 낮은 비율
- 과상향위험: 모든 적용 추천값이 실제값보다 0.50%p 초과 높은 비율
- 평가기간: 전체, 최근 2년, 최근 1년, 최근 6개월, 최근 3개월
- 평가항목: MAE, 중앙절대오차, ±0.20%p, ±0.30%p, ±0.50%p, 하한미달위험, 과상향위험, 평균편향
