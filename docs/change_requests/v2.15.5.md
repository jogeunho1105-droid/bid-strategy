# v2.15.5 변경요청서

작성일: 2026-08-20
기준 버전: v2.15.4
상태: Codex 구현·검증 완료, Work 승인 권고 및 사용자 운영 배포 승인 완료
변경 주제: 한국전력공사 부산울산본부 지역제한 감리의 기초금액별 참여업체 수 분리

## 1. 변경 목적

한국전력공사 부산울산본부 지역제한 용역 중 기초금액이 1억원 이상인 감리용역에는 3개 업체가 투찰할 수 있다는 운영 사실을 반영한다.

현행 v2.15.4는 부산울산본부 지역제한 감리를 기초금액과 관계없이 2개사로 제한하므로, 기초금액 1억원 이상인 입찰에서 실제 참여 가능한 업체3의 추천값이 화면과 엑셀에서 누락된다. v2.15.5에서는 해당 구간만 3개사로 변경하고 추천모델·가중치·한전 지역제한/전국입찰 이력 분리는 그대로 유지한다.

## 2. 적용 대상 입찰

아래 조건을 모두 만족할 때 적용한다.

| 조건 | 확정 기준 |
|---|---|
| 발주기관 | `한국전력공사 부산울산본부` |
| 용역분류 | 감리(`supervision`) |
| 입찰범위 | 기존 한전 고시금액 기준으로 지역제한으로 판정된 건 |
| 기초금액 | 100,000,000원 이상 |
| 참여업체 수 | 3개사 |
| 추천값 | 업체1 방향성 헷지 + 업체2 중심모델 + 업체3 라인 헷지 |

금액 경계는 기초금액 원 단위의 `이상(>=)`으로 적용한다. 따라서 기초금액이 정확히 100,000,000원이면 3개사 대상이다.

| 입찰 구간 | v2.15.4 | v2.15.5 |
|---|---:|---:|
| 부산울산본부 지역제한 감리, 기초금액 1억원 미만 | 2개사 | 2개사 유지 |
| 부산울산본부 지역제한 감리, 기초금액 1억원 이상 | 2개사 | 3개사 변경 |
| 부산울산본부 전국입찰 감리 | 3개사 | 3개사 유지 |
| 부산울산본부의 감리 외 용역 | 기존 3개사 | 기존 3개사 유지 |
| 경북본부·대구본부 지역제한 감리 | 1개사 | 1개사 유지 |

현재 한전 전용 참여업체 수 분기는 감리에만 적용되고 감리 외 용역은 이미 3개사 기준이다. 따라서 이번 코드 변경의 실제 대상은 위 조건의 부산울산본부 지역제한 감리이다.

## 3. 확정된 계산 기준

### 3.1 지역제한 판정

기존 v2.15.4 기준을 변경하지 않는다.

~~~text
추정가격 = 기초금액 ÷ 1.1

지역제한 = 추정가격 < 개찰연도별 고시금액
전국입찰 = 추정가격 >= 개찰연도별 고시금액
~~~

| 적용연도 | 고시금액 | 지역제한 기초금액 상한 |
|---|---:|---:|
| 2021~2022 | 210,000,000원 | 231,000,000원 미만 |
| 2023~2024 | 220,000,000원 | 242,000,000원 미만 |
| 2025~2026 | 230,000,000원 | 253,000,000원 미만 |

### 3.2 참여업체 수 계산

지역제한 판정 후 참여업체 수를 아래 순서로 결정한다.

~~~python
if 발주기관 == "한국전력공사 부산울산본부" and 입찰범위 == "지역제한":
    참여업체수 = 3 if 기초금액 >= 100_000_000 else 2
elif 발주기관 in ("한국전력공사 경북본부", "한국전력공사 대구본부") and 입찰범위 == "지역제한":
    참여업체수 = 1
else:
    참여업체수 = 기존_v2_15_4_기준
~~~

금액이 1억원 이상이더라도 먼저 지역제한으로 판정된 경우에만 이 분기를 적용한다. 고시금액 기준 이상인 전국입찰은 기존 전국입찰 3개사 로직을 그대로 사용한다.

### 3.3 추천값과 가중치

이번 변경에서는 추천값 산정식과 가중치를 변경하지 않는다.

| 업체 | 기존 역할 | v2.15.5 적용 |
|---|---|---|
| 업체1 | 부호 전이패턴과 직전 흐름을 반영한 방향성 헷지 | 유지 |
| 업체2 | 용역분류별 백테스트 최적 중심모델과 최근 90일 오버레이 | 유지 |
| 업체3 | 발주기관 이력의 0.02%p 라인 패턴을 이용한 라인 헷지 | 1억원 이상 부산 지역제한 감리에 추가 표시 |

업체2 평균혼합, 기관·분야별 내부 라우터, 최근 90일 보수 오버레이, 분위수 제한, 추천기준금액 계산은 v2.15.4와 동일하다.

## 4. 변경하지 않을 기존 로직

1. 운영 파일명 `입찰 앱.py`와 Streamlit Main file path를 유지한다.
2. 한전 감리는 지역제한 이력과 전국입찰 이력을 분리한다.
3. 부산울산본부 지역제한 감리의 기초금액 1억원 미만은 2개사 추천을 유지한다.
4. 경북본부·대구본부 지역제한 감리는 1개사 추천과 기존 최근흐름 보정을 유지한다.
5. 한전 전국입찰 감리는 전국입찰 실적 보유 3개사 추천을 유지한다.
6. 전기공사는 감리·설계·진단과 분리하고 1개사 단일추천을 유지한다.
7. 업체1·2·3의 추천식, 역할, 가중치와 최근 90일 오버레이를 변경하지 않는다.
8. 완전 동일 중복 제거와 동일일 안정 정렬을 유지한다.
9. 화면과 엑셀에는 실제 참여 가능한 업체의 추천값만 표시한다.
10. 사용자 승인 전 GitHub main 반영과 Streamlit 운영 배포를 하지 않는다.

- 평가항목: MAE, 중앙절대오차, ±0.20%p, ±0.30%p, ±0.50%p, 하한미달위험, 과상향위험, 평균편향

## 7. 화면·엑셀 표시 기준

### 7.1 화면

- 헤더와 모델 버전을 v2.15.5로 변경한다.
- 부산울산본부 지역제한 감리이면서 기초금액이 1억원 이상이면 `지역제한 · 참여 3개사`로 표시한다.
- 판정 근거에 `기초금액 1억원 이상으로 부산울산본부 참여 3개사`를 명시한다.
- 해당 건에는 업체1·업체2·업체3 추천사정률과 추천기준금액을 모두 표시한다.
- 기초금액 1억원 미만은 기존과 같이 `지역제한 · 참여 2개사`와 업체1·업체2만 표시한다.

### 7.2 엑셀

- `입찰범위`는 지역제한으로 유지한다.
- `참여업체 수`를 기초금액 구간에 따라 2 또는 3으로 기록한다.
- 1억원 이상 대상 건의 업체3 추천사정률·추천기준금액·모델·표본 수·산정근거를 채운다.
- 1억원 미만 대상 건의 업체3 관련 셀은 기존과 같이 참여대상 없음으로 유지한다.
- `입찰판정근거` 열에 입찰구분, 참여업체 수, 부산울산본부 1억원 이상 3개사 또는 미만 2개사 적용근거를 기록한다.
- 모델 버전을 v2.15.5로 기록한다.
- 화면과 엑셀의 참여업체 수, 추천사정률, 추천기준금액이 일치해야 한다.
