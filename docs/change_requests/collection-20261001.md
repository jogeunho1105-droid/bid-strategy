# 장기수집 신규 기준 원장 전환 — 2026-10-01

사용자가 이 대화에서 신규 기준 원장 전환, GitHub main 반영 및 Streamlit 운영 배포를 명시적으로 승인했다. 기존 원장과 원본 ZIP은 수정하지 않는다. 기존 원장은 동결 백업 및 과거 평가 재현용이고, 신규 원장에 병합하지 않는다.

## 변경 범위

- 검증 완료 251/252 작업의 원천 112,848행을 사용한다. 실패·이전 재시도·부분 Excel은 제외한다.
- 사건키는 공고번호/정정차수, 개찰일, 기관, 공고명, 기초금액이다. 용역/전기공사 중복 721키는 운영 사건당 한 번 반영하고 양쪽 원천 파일/행 추적정보를 보존한다.
- 운영 112,127행을 구성한다. 같은 사건의 분류는 용역 출처를 우선하고 기존 공고명 중심 분류 규칙을 그대로 적용한다. 검색조건만으로 전기공사로 확정하지 않는다.
- 두 원문 업종을 기존 분류기에 각각 적용하면 분류가 달라지는 496키(학습 후보 72건)는 별도 분류확인 경고로 관리한다. 대표값은 용역 원문 우선정책이며 실제 업종의 정답으로 검증한 값은 아니다. 두 업종 원문·분류결과·출처는 `분류확인` 시트와 별도 비공개 보관자료에 보존한다. 기존 분류기와 학습 정책은 유지하고 이 확인대상만 임의 새 업종으로 재작성하지 않는다.
- 품질상태와 빈값을 보존한다. 숫자 예가/1순위 모두 87,539행, 예가만 3,552행, 예가 숫자 없음 21,757행은 원천행 기준이다. 학습 후보수와 혼동하지 않는다.
- 공고명·기관 누락, 날짜 미확인·미래 개찰, abs(사정률)>=10 또는 무한값은 기존 품질경계에 따라 표시한다. 잘못된 값의 자동 수정이나 0 대입은 하지 않는다.
- 수집 지역을 원천값으로 사용한다. 실제 참가제한 검증과 분리한다.
- 기존 추천식, 가중치, 모델/지역·전국 판정, 추천표와 기존 Excel 첫 시트/열순서는 유지한다. 출처정보는 별도 화면 안내 및 추가 Excel `데이터출처` 시트로 표시한다.

## 안전한 적용과 재현

원천·회사자료는 공개 저장소에 포함하지 않는다. 관리자 업로드 Excel의 첫 시트는 운영 사건표이고, `데이터출처`는 버전·숫자상태·품질경고·미해결 예외를 담는다. `원천행출처` 시트 및 비공개 source_rows.csv.gz, source_excel_lineage.csv.gz는 전체 원천행 출처를 추적한다.

관리자 업로드 시 운영 내용의 정규화 SHA-256과 행수를 확인한다. 학습 정제본 외에 품질상태를 포함한 버전별 운영 원장을 별도로 보존한다. 기존 앱 history.pkl/history_quality.json이 있다면 최초 전환 시 별도 폴더에 복사한다. 기존 `낙찰데이터.xlsx`는 원본과 동일한 해시의 비공개 동결 사본으로 보관한다. 공개 GitHub에는 코드·절차·집계 회귀결과만 올린다.

Streamlit 파일 저장소는 영구 보관을 보장하는 저장소가 아니다. 재생성 등으로 이력이 사라지면 검증된 같은 Excel을 관리자 업로드로 복구한다. 기존 앱의 관리 비밀번호·Secrets는 변경하지 않는다.

## 검증 및 미해결

원본 Excel 1,251개, 112,848행, 2,031,264셀을 CSV 원천행 JSON과 비교했다. 문자/식별자는 정확히 비교하고 숫자는 직렬화 오차에 한해 절대 1e-10 허용한다. 파일 SHA-256은 정확히 일치해야 한다.

2024-05-29 전기공사 1개 작업은 화면29/Excel26으로 미해결이다. 부분자료를 합산하거나 누락공고를 추정 생성하지 않는다. 이 경고를 화면과 두 다운로드 Excel에 표시한다.

전체 일자별 rolling 평가를 기존 엔진과 실제 S1~S5/자동 전략으로 전후 수행한다. burn-in 150건, 같은 날·미래 결과 제외, 기존 한전 지역제한 제외조건, 개발 종료 2025-08-31, 보류 2025-09-01~2026-09-01 및 최종검증 2026-06-01~2026-09-23을 고정한다. 정책 적용일은 소급 변경하지 않는다. 정정번호 최고차수를 과거 이력 전체에 소급 적용하지 않는다.

가격구간 통과는 기존 v2.15.7의 엄격 부등식 `예가 < 추천 < 1순위`다. 1순위 누락/비정상은 분모 제외, 숫자 비양수 구간은 기존 방식대로 실패다. 커버 최소오차와 중심/단일 오차를 분리한다. 전체 구성 변화와 동일 사건/동일 결과값 코호트를 따로 보고한다. 성능을 보고 전략·가중치를 다시 선택하지 않는다.

최종 수치 및 운영 스모크 확인은 `collection-20261001-verification.md`에 기록한다.

## 비공개 작업폴더에서 재현

다음 스크립트는 사용자가 지정한 비공개 출력폴더에만 운영자료를 만든다. 입력 ZIP·기존 Excel은 읽기 전용이며 기존 동결 사본의 해시가 다르면 중단한다. 원천 파일명·기관·공고명·사업자번호가 포함된 상세자료는 커밋하지 않는다.

```text
python analysis/build_collected_ledger.py --archive <원본ZIP> --legacy <기존Excel> --output <비공개폴더>
python analysis/verify_collection_sources.py --archive <원본ZIP> --out <비공개폴더>
python analysis/export_collected_ledger.py --source-dir <비공개폴더>
python analysis/ledger_regression.py --source <비공개폴더>/legacy_frozen.xlsx --out <비공개폴더>/regression-old
python analysis/ledger_regression.py --source <비공개폴더>/operational.pkl --out <비공개폴더>/regression-new
python analysis/compare_ledger_regression.py --old <비공개폴더>/regression-old --new <비공개폴더>/regression-new --out analysis/results/collection-20261001
```

분류확인 경고는 원문 데이터값을 고치거나 추천식을 변경하지 않는다. 회귀검증의 원천열 내용 해시와 배포 Excel의 원천열 내용 해시가 같음을 확인한다. 기존 학습 로직에 사용되지 않는 경고·출처 보관열의 추가는 입력값 변경과 구분한다.
