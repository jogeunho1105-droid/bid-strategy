## 구현 범위

- 앱 헤더·화면·Excel 모델 버전 v2.15.6 반영
- 사이드바에 최근 1년 보유업체 전체 가상 낙찰률 14.24%(1,646/11,563건) 표시
- 중심·단일 1개 값 가상 낙찰률 9.18%와 엄격 판정식 표시
- 반사실적 가상 낙찰률의 해석 한계 및 미검증 상향보정 미반영 표시
- 업로드 낙찰이력의 최초일·최종일 데이터 품질 정보 추가
- 추천표 Excel에 `사후낙찰검증`, `검증기준` 시트 추가
- 적용 추천순번, 실제 투찰사정률, 예가/기초, 1순위 사정률, 낙찰하한율, 무효·실격 여부와 최종결과 입력 구조 추가
- 추천기준 및 실제투찰 기준 엄격 부등식 자동판정 추가

## 추천식 반영 결정

추천값 계산식과 가중치는 v2.15.5 운영 기준을 유지했다. 개발구간에서 선택된 다중참여 +0.12%p, 전기공사 +0.19%p, 한전 지역 1개사 +0.12%p 상향보정은 최근 1년 고정 보류구간의 일자 블록 95% 신뢰구간이 0을 포함하므로 반영하지 않았다.
