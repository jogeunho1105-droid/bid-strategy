## 1. 구현 내용

- 모델과 화면·Excel 다운로드 버전을 v2.15.5로 변경했다.
- 한국전력공사 부산울산본부 지역제한 감리의 기초금액이 1억원 미만이면 2개사, 1억원 이상이면 3개사로 분리했다.
- 기초금액이 정확히 100,000,000원인 경우 3개사로 판정한다.
- 1억원 이상 대상 건에는 기존 업체3 라인 헷지 추천값을 추가 표시한다.
- 판정 근거에 `기초금액 1억원 이상으로 부산울산본부 참여 3개사` 또는 1억원 미만 2개사 근거를 표시한다.
- 경북·대구 지역제한 1개사, 한전 전국입찰 3개사, 전기공사 1개사, 비감리 3개사 로직과 모든 추천 가중치를 유지했다.

## 5. 비회귀 확인

- 변경 대상 외 45,698건의 추천결과는 v2.15.4와 완전히 동일했다.
- 행별 최소오차가 악화된 건은 0건이다.
- 업체수 변경은 승인된 부산울산본부 지역제한 감리 1억원 이상 구간에만 발생했다.
- 지역제한/전국입찰 이력 선택과 추천값 산정 가중치는 변경하지 않았다.

다중 추천의 최소오차 평가는 후보가 늘면 구조적으로 악화되지 않으므로, 성능 개선은 보조 근거로만 해석한다. 변경의 1차 근거는 실제 3개 업체 투찰 가능이라는 승인된 운영규칙이다. 최근 1년 대상 표본 20건과 최근 3개월 4건은 작으므로 세부 적중률은 참고치다.

## 6. 운영 배포 검증 조건

- 로컬 실행용 Python 환경에 Streamlit 패키지가 없어 HTTP 화면 스모크 테스트는 실행하지 못했다.
- Streamlit Cloud는 `requirements.txt`에 따라 의존성을 설치하므로, 배포 승인 후 운영 배포 단계에서 앱 부팅·첫 화면·버전·샘플 업로드를 확인해야 한다.
- Work의 최종 승인 권고와 사용자 운영 배포 승인을 받았으며, GitHub·Streamlit 배포 단계에서 아래 검증을 완료한다.
