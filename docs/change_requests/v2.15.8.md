# v2.15.8 변경요청서

## 1. 변경 목적

현재 Streamlit 요약표는 공고명과 업체별 추천 사정률 사이에 업체별 `추천기준금액` 열이 함께 표시되어 가로 폭이 지나치게 넓고, 핵심 비교항목인 중심모델군과 업체1·2·3 추천값을 한눈에 확인하기 어렵다.

이번 변경은 **요약표의 열 순서를 재배치하고 요약표에서만 추천기준금액 열을 제외**하여 가독성을 개선하는 UI 정리이다. 추천식·업체수 판정·추천기준금액 계산·상세화면·Excel 출력은 변경하지 않는다.

- 현재 버전: `v2.15.7`
- 목표 버전: `v2.15.8`
- 변경 성격: 화면 요약표 표시 전용
- 기준 화면: 2026-09-15 사용자 표시 순서

- 데이터 품질 경고

## 3. 확정된 화면 변경 기준

### 3.1 요약표 열 순서

요약표의 최종 열 순서는 다음과 같이 고정한다.

| 순서 | 열 이름 |
|---:|---|
| 1 | 중심모델군 |
| 2 | 공고명 |
| 3 | 업체1추천 |
| 4 | 업체2추천 |
| 5 | 업체3추천 |
| 6 | 비고 |

`pandas.DataFrame`은 위 순서대로 생성하거나 최종 컬럼 선택을 통해 순서를 강제한다.

### 3.2 요약표에서 제외할 열

아래 3개 열은 **요약표에서만** 제거한다.

- `업체1추천기준금액`
- `업체2추천기준금액`
- `업체3추천기준금액`

요약표 전용 `display_amounts` 생성 코드가 더 이상 사용되지 않으면 요약표 블록 안에서만 제거할 수 있다. 단, `recommendation_reference_amount()` 함수 및 상세화면·Excel에서의 사용은 유지한다.

### 3.3 요약표 제목

기존:

```text
📋 최대 3개 업체 추천 사정률·추천기준금액 — YYYY.MM.DD (N건)
```

변경:

```text
📋 최대 3개 업체 추천 사정률 — YYYY.MM.DD (N건)
```

### 3.4 기존 표시값 유지

- `업체1추천`, `업체2추천`, `업체3추천`의 값과 소수점 형식은 유지한다.
- 실제 참여 가능 업체 수를 초과하는 열의 `참여대상 없음` 표시는 유지한다.
- 계산 불가 시 `없음` 또는 기존 오류 표시방식을 유지한다.
- `비고`의 입찰구분, 참여업체 수, 판정근거, 업체별 산정근거는 유지한다.
- `중심모델군` 값은 기존 `model_family_info(b)[1]` 결과를 그대로 사용한다.

## 4. 변경하지 않을 기존 로직

다음 로직은 절대 변경하지 않는다.

1. 업체1 방향성 헷지 추천식
2. 업체2 중심모델 추천식
3. 업체3 라인 헷지 추천식
4. 최근 90일 가중치 및 drift
5. 전기공사 단일참여 전용 로직
6. 한전 지역제한·전국입찰 이력 분리
7. 부산울산본부·경북본부·대구본부 업체 수 판정
8. 공동주택 및 주거시설 감리 모델군 분류
9. `추천기준금액` 계산식
10. 건별 상세화면의 추천기준금액 표시
11. Excel의 업체별 추천기준금액 및 산정근거
12. 사후낙찰검증 시트
13. 낙찰이력 데이터 품질 경고
14. 기존 백테스트·감사 요약 수치

이번 변경을 이유로 `bid_engine.py`, `bid_rules.py`의 계산 로직을 수정하지 않는다.

안전성을 위해 최종 DataFrame 컬럼 순서를 명시적으로 고정할 수 있다.

    "중심모델군",

관련 없는 함수·모듈·모델 코드는 정리하거나 리팩터링하지 않는다.

## 6. 백테스트 및 회귀검증 방법

이번 변경은 화면 표시 전용이므로 모델 성능을 새로 해석하지 않는다. 대신 기존 추천결과의 무변경을 회귀검증한다.

### 6.1 추천결과 무변경 검사

동일 입력 자료로 v2.15.7과 v2.15.8을 비교한다.

- 공고별 참여업체 수 동일
- 업체1·2·3 추천 사정률 동일
- 추천기준금액 동일
- 입찰범위 및 판정근거 동일
- 모델군 동일
- 산정근거 동일
- Excel 값 동일

허용 차이:

```text
추천 사정률 최대 차이 = 0.0000%p
추천기준금액 차이 = 0원
```

### 6.2 화면 회귀검사

최소 5건의 혼합 샘플을 사용한다.

- 3개사 참여 공고
- 2개사 참여 공고
- 1개사 참여 공고
- 전기공사 단일참여
- `참여대상 없음`이 포함되는 공고

검사 항목:

1. 열 순서가 정확히 `중심모델군 → 공고명 → 업체1추천 → 업체2추천 → 업체3추천 → 비고`
2. 요약표에 추천기준금액 3개 열이 없음
3. 제목에 `·추천기준금액` 문구가 없음
4. 업체별 추천값과 `참여대상 없음` 표시가 정상
5. 비고의 줄바꿈과 산정근거가 유지됨
6. 건별 상세의 추천기준금액은 정상 표시됨
7. Excel의 추천기준금액은 정상 출력됨

### 6.3 기술검사

- Python 문법 검사 통과
- 기존 자동 단위·Excel 검사 전체 통과
- Streamlit 앱 부팅 및 첫 화면 HTTP 정상
- 샘플 입찰서류함 업로드 정상
- Excel 다운로드 정상
- `git diff --check` 통과
