# 2026-09-02 낙찰이력 엄격 롤링 백테스트 검토

## 결론

이번 자료로 검증한 결과, **v2.15.5 운영 추천식은 유지**한다.
최근 90일 가중치 5개 안과 핵심 중심모델 12개 안을 개발구간에서 선택한 뒤 최근 1년 고정 보류구간에서 검증했으나, 사전에 정한 반영 기준을 모두 통과한 변경안은 없었다.

결과가 좋아 보이도록 보류구간을 보며 후보를 고르거나, 2~3개 추천 중 사후 최소오차만을 단일 예측 정확도로 해석하지 않았다.

## 누수 방지 및 후보 선택 절차

1. 각 개찰일의 모든 입찰을 해당 일자 이전 이력으로만 예측한다.
2. 같은 일자의 실제 결과는 그 일자 예측이 모두 끝난 뒤 학습 이력에 추가한다.
3. 2025-08-31까지를 개발구간으로 사용한다.
4. 2025-09-01~2026-09-01은 후보 선택에 쓰지 않는 최종 보류구간으로 잠근다.
5. 개발구간 개선폭, 시간 폴드 안정성, 보류구간 개선폭, ±0.30%p 적중률, 일자 블록 부트스트랩 95% 신뢰구간을 모두 확인한다.
6. 다중추천은 `최소오차=커버리지`, 업체2 중심추천은 `단일오차=예측력`으로 분리한다.

전기공사 보수 대안은 개발 MAE 개선이 0.00034%p에 그쳤고 최근 1년은 사실상 동일·미세 악화했다. 한전 지역제한 1개사 보수 대안도 개발 개선이 0.00047%p여서 채택 기준에 미달했다.

## 반영 사항

- 운영 앱 추천식과 v2.15.5 표시 버전은 유지한다.
- 동일일 누수를 막는 엄격 롤링 감사 코드를 추가한다.
- 운영 커버리지와 중심/단일 예측력을 분리한 결과 파일을 남긴다.
- 개발구간 선택과 최근 1년 고정 보류구간 검증을 이후 변경의 기본 승인 절차로 사용한다.
- 전기공사 지역 누락률이 51.4%이므로 지역 요소를 이용한 추가 모델 튜닝보다 원천 지역값 보완을 우선한다.

## 공고별 가상 낙찰률 추가 검증

### 판정 정의

당사가 공고별 운영 추천값으로 실제 참여 가능 업체를 모두 투찰했다고 가정하고 다음 엄격 부등식으로 평가했다.

`예가/기초(0%) < 추천사정율 < 1순위사정율(0%)`

추천값이 어느 한쪽 경계와 같으면 낙찰이 아니다. 여러 업체 중 하나라도 조건을 만족하면 공고 단위 가상 낙찰로 집계했다. 1순위 사정율이 누락됐거나 `1순위 사정율 ≤ 예가/기초`여서 양수 낙찰구간이 없는 건은 손실로 세지 않고 판정불가로 제외했다.

기존 rolling 결과 46,167건과 원본의 1순위 사정율을 개찰일·공고번호·공고명·발주기관·기초금액·예가/기초 및 동일키 내 순번으로 연결했다. 46,167건 모두 1:1 일치했고, 핵심 수치의 최대 차이는 0이었다.

최근 1년을 보지 않고 2025-08-31까지의 개발구간에서 모든 운영 추천값에 동일한 `-0.10~+0.20%p` 보정을 적용하는 저복잡도 후보만 선택했다.

세 후보 모두 일자 블록 95% 신뢰구간이 0을 포함해 개선을 확정할 수 없었다. 특히 한전 지역 1개사는 보류구간 개선이 없었다. 따라서 새 가상 낙찰 지표를 본 뒤 추천값을 사후 상향하지 않으며 운영 추천식은 유지한다.

## 해석 한계

이 자료에는 당사 실제 투찰값·업체별 배정 추천값·낙찰하한율 적용 후 금액·당사 낙찰 여부가 없다. 따라서 위 수치는 사용자가 정의한 조건으로 과거 공고에 추천값을 대입한 반사실적 가상 낙찰률이며, 당사의 관측된 실제 낙찰률이나 하한미달률은 아니다.
