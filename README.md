# 📊 투찰전략 분석 시스템 v2.15.6

낙찰이력을 분석해 입찰 참여조건에 맞는 최대 3개 업체의 추천 사정률, 추천기준금액과 산정 근거를 제공하는 버전입니다.
화면과 엑셀에는 실제 참여 가능한 업체의 최종 추천값만 표시합니다.

이번 버전은 2026-09-01까지의 낙찰이력으로 검증한 가상 낙찰성과를 프로그램에 표시하고, 추천표 Excel에 `사후낙찰검증` 기록지를 추가한 검증·수집 개선 버전입니다.
추천식·가중치와 지역제한/전국입찰 이력 분리는 v2.15.5 운영 기준을 그대로 유지합니다.
개발구간에서 선택된 일괄 상향보정 후보는 최근 1년 고정 보류구간의 신뢰구간을 통과하지 못해 적용하지 않았습니다.

## 전기공사 단일참여 추천 기준

전기공사는 기존 감리·설계·진단 용역과 낙찰 패턴 및 업체수 구조가 다르므로 별도 업종으로 분리합니다.
당사 참여가 1개 업체인 경우 업체1·2·3 분산추천을 적용하지 않고, 다음 기준을 혼합해 **단일 1순위 추천값**을 산정합니다.

| 적용요소 | 내용 |
|---|---|
| 동일 발주기관 | 해당 발주기관 전기공사 최근 이력 우선 |
| 동일 지역 | 지역 또는 권역의 예가/기초 흐름 반영 |
| 금액구간 | 기초금액 규모별 낙찰 패턴 반영 |
| 업체수구간 | 전체 참여업체 수에 따른 경쟁강도 반영 |
| 최근 1년 | 최근 시장 흐름의 중심값 반영 |
| 최근 90일 | 단기 변동성 반영. 변동성이 크면 가중치를 낮춤 |
| 최종 제한 | 최근 전기공사 이력의 5~95% 분위수 범위로 과도한 보정 제한 |

백테스트 결과 전기공사 단일추천은 최근 1년 3,852건 기준 MAE 약 0.4773%p로 확인되었습니다. 대안 가중치의 개선 근거가 충분하지 않아 기존 가중치를 유지합니다.
따라서 전기공사는 3개사 분산 커버가 불가능하므로 단일값을 “1순위 적용값”으로 보고, 하한미달 위험과 과상향 위험을 함께 검토합니다.


## 한국전력공사 감리 입찰 분류

고시금액은 입찰서류함의 마감연도를 기준으로 2년 단위 적용합니다. 추정가격은 `기초금액 ÷ 1.1`로 계산하며, 추정가격이 고시금액보다 작은 경우 지역제한으로 분류합니다.

| 적용연도 | 고시금액 |
|---|---:|
| 2021~2022년 | 2.1억원 |
| 2023~2024년 | 2.2억원 |
| 2025~2026년 | 2.3억원 |

| 발주기관·입찰구분 | 참여업체 수 | 추천값 |
|---|---:|---|
| 경북본부·대구본부 지역제한 | 1개사 | 백테스트 최적모델 중심값에 최근 3/5/10건 지역제한 흐름을 보정한 1개 추천값 |
| 부산울산본부 지역제한·기초금액 1억원 미만 | 2개사 | 패턴 추천값 + 백테스트 최적모델 중심값 |
| 부산울산본부 지역제한·기초금액 1억원 이상 | 3개사 | 업체1 방향성 헷지 + 업체2 중심모델 + 업체3 라인 헷지 |
| 한국전력공사 전국입찰 감리용역 | 3개사 | 전국입찰 실적 보유 3개사에 업체 1·2·3 추천 |
| 한국전력공사 진단·설계·기타 용역 | 3개사 | 업체 1·2·3 기존 추천방식 |
| 한국전력공사 외 모든 용역 | 3개사 | 업체 1·2·3 기존 추천방식 |

- 한전 감리 지역제한은 지역제한 이력만 사용합니다.
- 한전 감리 전국입찰은 전국입찰 이력만 사용하며 타 지역의 지역제한 이력은 제외합니다.
- 경북 소재 2개사는 한국전력공사 전국입찰 실적이 부족하므로 전국 감리 추천 대상에서 제외합니다.
- 한국전력공사 전국 감리 추천값은 전국입찰에 참여 가능한 3개사에 대해서만 제공합니다.
- 입찰서류함에는 부산울산·경북·대구 외 지역제한 입찰을 넣지 않는 운영규칙을 적용합니다.
- 한국전력공사 진단·설계·기타 용역과 한국전력공사 외 입찰은 기존 분석 및 3개 업체 추천방식을 유지합니다.
- 고정된 업체1·2·3 열에서 참여하지 않는 업체는 `참여대상 없음`으로 표시합니다.

## 2026-09-02 엄격 재검증

2026-09-01까지의 최신 낙찰이력으로 같은 일자 결과를 사용하지 않는 일자별 rolling backtest를 다시 수행했습니다. 후보는 2025-08-31까지의 개발구간에서만 선택하고, 2025-09-01~2026-09-01 최근 1년은 고정 보류구간으로 한 번만 검증했습니다.

| 평가 방식 | 최근 1년 표본 | MAE | ±0.30%p |
|---|---:|---:|---:|
| 실제 참여수 반영 운영 커버리지 | 11,949건 | 0.3848%p | 52.44% |
| 중심추천 또는 단일추천 엄격 평가 | 11,949건 | 0.4889%p | 38.07% |
| 전기공사 단일참여 | 3,856건 | 0.4795%p | 39.06% |
| 한전 지역제한 1개사 | 267건 | 0.4236%p | 44.94% |

다중추천 최소오차는 2~3개 업체 투찰의 커버리지 지표이며 업체2 하나의 예측 정확도가 아닙니다. 최근 90일 가중치와 핵심 중심모델 후보를 개발/보류 절차로 검증했으나 사전 승인기준을 모두 통과한 대안은 없어 **v2.15.5 운영 추천식을 유지**합니다.

유효 46,319건 중 지역 누락이 27,348건(59.0%), 전기공사 11,916건 중 지역 누락이 6,122건(51.4%)이므로 전기공사 지역모델 조정보다 원천 지역값 보완을 우선합니다. 상세 절차와 후보 탈락 근거는 `docs/reviews/strict_backtest_20260902.md`에 기록했습니다.

### 공고별 가상 낙찰률 검증

당사가 공고별 운영 추천값으로 실제 참여 가능 업체를 모두 투찰했다고 가정하고, 사용자가 지정한 아래 엄격 부등식을 만족한 경우에만 가상 낙찰로 판정합니다.

`예가/기초(0%) < 추천사정율 < 1순위사정율(0%)`

- 추천값이 양쪽 경계와 같으면 낙찰로 보지 않습니다.
- 여러 업체 중 하나라도 조건을 만족하면 해당 공고를 가상 낙찰 1건으로 집계합니다.
- 1순위 사정율이 없거나 `1순위 사정율 ≤ 예가/기초`인 공고는 손실이 아니라 판정불가로 제외합니다.
- 이는 실제 당사 참여기록이 아니라 과거 공고에 추천값을 적용한 반사실적 **가상 낙찰률**입니다.

| 최근 1년 평가 | 판정가능 표본 | 가상 낙찰건수 | 가상 낙찰률 |
|---|---:|---:|---:|
| 실제 참여 가능 보유업체 전체 | 11,563건 | 1,646건 | 14.24% |
| 중심추천 또는 단일추천 1개 값 | 11,563건 | 1,062건 | 9.18% |
| 1개사 참여 공고 | 3,823건 | 302건 | 7.90% |
| 3개사 참여 공고 | 7,644건 | 1,335건 | 17.46% |

최근 1년 전체 11,949건 중 1순위 사정율 누락 300건과 낙찰구간 비양수 86건을 제외했습니다. 판정가능 11,563건의 실패는 전 추천이 예가/기초 이하 4,557건(39.41%), 전 추천이 1순위 이상 3,152건(27.26%), 추천값들이 양쪽에 있지만 낙찰구간을 비킨 경우 2,208건(19.09%)입니다.

개발구간에서만 단순 상향보정을 선택한 결과 다중참여 `+0.12%p`, 전기공사 단일 `+0.19%p`, 한전 지역 1개사 `+0.12%p`가 후보가 됐습니다. 그러나 최근 1년 고정 보류구간의 일자 블록 95% 신뢰구간이 모두 0을 포함했고, 한전 지역 1개사는 개선이 0%p였습니다. 따라서 가상 낙찰률을 사후적으로 높이기 위한 보정은 반영하지 않고 **v2.15.5 운영 추천식을 유지**합니다.

개선값을 보조값으로 병행 표시하지 않습니다. 앱 내부에서 아래 조건에 해당하는 경우만 개선모델을 선택하고, 화면과 엑셀에는 최종 업체1·업체2·업체3 추천값만 표시합니다.

## 사용 절차

1. 배포자 관리에서 낙찰이력 파일을 업로드합니다.
2. 투찰전략 분석 화면에서 나라장터 입찰서류함 파일을 업로드합니다.
3. 요약표의 `업체1추천`, `업체2추천`, `업체3추천`과 각 `추천기준금액`을 확인합니다. 한전 감리는 입찰구분과 참여업체 수가 `비고` 첫 줄에 표시되고 각 근거는 업체별로 줄바꿈됩니다.
4. 추천기준금액은 낙찰하한율을 반영한 최종 투찰금액이 아니므로 공고별 하한율을 별도로 적용합니다.
5. 건별 상세의 사정률 흐름 차트를 확인한 뒤 최종 투찰값을 결정합니다.
